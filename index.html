About Me

I am Qiyang Li (李启扬), a third-year undergraduate studying Software Engineering at Beihang University. My research interests include agents, reinforcement learning (RL), and multimodal large language models (MLLMs).

My recent work explores agents for software development and research, including design-guided web generation, unit test generation, program repair trajectories, literature-grounded ideation, and interface data curation.

Research Interests

  • Agents: tool use, planning and memory, and multi-agent collaboration.
  • Reinforcement Learning (RL): learning from interaction and feedback to improve agent decision-making and task execution.
  • Multimodal Large Language Models (MLLMs): joint vision–language understanding, and reasoning and interaction grounded in multimodal information.

Method overview

DesignCoder: Bringing Professional Web Design to Agentic Code Generation

Ziteng Xue1, XiMing Xing2, Juncheng Hu1, Qiyang Li1, Guotao Liang1, Yuan Shui1, Mengcheng Yan1, Jing Zhang1, Qian Yu1

1 Beihang University (First institution)
2 Tencent (Second institution)

Under review · ICLR 2027

Explicit design specifications connect user intent to agentic web generation. The framework combines design planning, specification and asset retrieval, and trajectory-based training.

I was responsible for designing and implementing the core design-specification generation module, connecting intent parsing, dimension-wise weighted retrieval, and specification synthesis to produce DESIGN.md for web code generation. I also designed and conducted cross-model comparisons and homogenization evaluations across visual, color, and layout dimensions.

Method overview

Cover More, Spend Less: LLM-Based Unit Test Generation with Value-Guided Path Ranking and Reachability Checking

Zhiwen Luo1, Qiyang Li1, Lin Shi1, Li Zhang1

1 Beihang University (Sole institution)

Under review · FSE 2027

PathSieveUT ranks execution paths by value and checks reachability before generating unit tests, reducing redundant analysis while targeting useful coverage.

I organized the evaluation data, ran six baselines, and analyzed coverage and generation costs across Java repositories.

Open-source Projects

RepairWeave

Subtask interactions and historical context in agentic program repair

An empirical study of 1,500 public repair trajectories from three agents on SWE-bench Verified. I study how local repair goals, accumulated localization evidence, and validation feedback relate to final outcomes.

Observational analysis; current findings are snapshot-specific, with parser/snapshot reconciliation documented in the repository.

OrbitResearch / Orbit+

Literature-grounded research assistance and multi-agent ideation

A research workbench combining a local PDF library and retrieval-grounded Q&A with Proposer–Critic discussion loops. A human-selected proposal is handed to a Planner to develop an experiment plan.

An interactive research prototype; effectiveness and novelty gains have not yet been established.

GitHub / Code ↗

UI Quality Curator

Evidence-based curation of interface screenshots

A two-stage prototype that turns structured visual evidence into page-function and domain classifications, rubric-based quality scores, and reproducible curation decisions. The repository includes experiments on 100 fixed samples.

No human gold standard yet; curation distributions do not establish accuracy or downstream improvement.
